# HR Analytics Power BI Dashboard

## 📊 Project Overview

This project is an interactive **HR Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard helps analyze employee data and provides insights into **employee performance, attendance, attrition, and workforce trends**.

## 🎯 Objectives

* Analyze employee performance and attendance.
* Understand employee attrition trends.
* Identify important workforce patterns.
* Create interactive and easy-to-understand visualizations.
* Support data-driven HR decision-making.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **Microsoft Excel**
* **Data Cleaning & Transformation**
* **Data Analysis**
* **Data Visualization**

## 📌 Key Features

* Employee performance analysis
* Attendance analysis
* Attrition analysis
* Workforce trend analysis
* Interactive charts and visualizations
* Filters and slicers for data exploration
* HR insights through an interactive dashboard

## 🔄 Project Workflow

1. Collected the HR dataset.
2. Cleaned and prepared the data.
3. Transformed the data using Power Query.
4. Analyzed the employee data.
5. Created visualizations in Power BI.
6. Developed an interactive HR dashboard.
7. Identified useful workforce insights.

## 📈 Dashboard Insights

The dashboard can be used to explore:

* Total employees
* Employee attendance
* Employee performance
* Attrition patterns
* Workforce trends
* Department-wise employee information
